# 📊 Customer Behavior Dashboard

## 📌 Project Overview

This project focuses on analyzing **customer behavior data using Power BI**. The dashboard provides an interactive view of customer purchasing patterns, key performance indicators, and important business trends.

The goal of the project is to transform raw customer data into meaningful visual insights that can support **data-driven business decisions**.

## 🎯 Objectives

* Analyze customer purchasing behavior.
* Identify important customer trends and patterns.
* Track key performance indicators (KPIs).
* Create interactive and easy-to-understand visualizations.
* Generate insights that can support business decision-making.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* Data Cleaning & Transformation
* Data Visualization

## 📊 Dashboard Features

* Interactive KPI cards
* Customer behavior analysis
* Purchasing pattern analysis
* Trend analysis
* Interactive charts and visualizations
* Filters and slicers for detailed analysis

## 🔍 Key Insights

The dashboard helps understand:

* Customer purchasing patterns
* Customer performance and trends
* Important business KPIs
* Differences between customer segments
* Areas that can support better business decisions
